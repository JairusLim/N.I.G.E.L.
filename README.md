# Nigel

**Neural Intelligence for Guidance, Execution & Logistics**

Nigel is a fully local AI assistant designed to run on dedicated hardware. The goal is to create an intelligent room assistant capable of natural conversation, memory, room automation, and personal assistance without relying on cloud AI services.

---

## Goals

- Run entirely locally
- Natural voice conversations
- Long-term memory
- Room automation
- Smart device control
- Personal knowledge base
- Extensible architecture
- Modern web dashboard (Nigel OS)

---
